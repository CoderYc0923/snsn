# SnSn：移动端影子跟读学习工具 — 技术方案

> 日期：2026-09-21  
> 状态：待评审  
> 对标产品：Miraa（双语字幕 + 影子跟读），**仅移动端 Web 第一版**

---

## 1. 产品目标

做一款**手机浏览器可用**的日语（可扩展多语）学习工具：用户选本地视频/音频 → 服务端抽音并转写 → 得到带时间轴的**日语原文 + 中文译文** → 在临摹 Miraa 的界面里按句听、跟读、对比。

### 1.1 第一版必须做到（MVP）

| 能力 | 说明 |
|------|------|
| 导入素材 | 手机选本地视频或音频（相册 / 文件） |
| 抽音 + 转写 | 服务端 ffmpeg 抽音 → 百炼 Paraformer 出带时间轴日语字幕 |
| 双语 | 日语原文 + 中文译文（译文可二次调用翻译/LLM） |
| 播放器 | 按句高亮、变速、单句循环 |
| 影子跟读 | 听 → 跟读录音 → 与原声对比回放 |
| 原片存储策略 | **原视频/音频不落服务器长期存储**；字幕与进度存在用户设备 |
| UI | **交互与信息架构临摹 Miraa**（见第 6 节） |

### 1.2 第一版明确不做

- PC 专属布局与桌面壳（Tauri 等）
- YouTube / 播客外链抓取
- 本机 Whisper / Vosk 作为默认引擎
- 发音打分、账号体系、付费订阅、多设备云同步原片
- 逐像素复制 Miraa 商标、插画、专有视觉资产（临摹的是流程与版式逻辑）

## 2. 已确认约束

| 项 | 结论 |
|----|------|
| 端 | **仅移动端**优先；同一套页面在大屏可用但不做 PC 优化 |
| 前端 | **Svelte + Vite + TypeScript**；组件与样式全部自维护；按移动端浏览器（iOS Safari / Android Chrome）适配 |
| 部署 | 阿里云轻量 **2 核 2G**：Nginx 静态前端 + Python 工具服务 |
| 转写 | **阿里云百炼 Paraformer**（`paraformer-v2` + `language_hints: ["ja"]`） |
| 临时对象 | 音频短暂上传 **北京 OSS（cn-beijing）**；百炼同区拉取；任务结束立即删除 |
| 轻量机地域 | 可与北京不同；机器→OSS 可用公网上传（上传入流量一般免费）；OSS→Paraformer 同区即可 |
| 原片 | **默认离线缓存到 IndexedDB**；打开时先读缓存，失败则让用户重选本地文件（不重转写） |
| 换设备 | 导出/导入：默认可含字幕；可选含原片缓存。仅导字幕时导入后需重选文件补缓存 |
| 存储设置 | **只展示已用空间**（不展示剩余配额）；按经验阈值着色；支持按课清缓存 / 删整课 |
| 双语 | 转写出日语；中文由翻译链路补齐（可与转写流水线串联） |

## 3. 总体架构

```
┌─────────────────────────────┐
│  手机浏览器（PWA 友好）        │
│  · 选文件 / 本地播放           │
│  · IndexedDB：字幕、进度、录音  │
│  · UI 临摹 Miraa               │
└──────────────┬──────────────┘
               │ HTTPS：上传音视频（处理用）
               │ 返回：字幕 JSON（含时间轴）
               ▼
┌─────────────────────────────┐
│  轻量应用服务器 2核2G          │
│  Nginx：静态前端               │
│  Python FastAPI：              │
│    收文件 → ffmpeg 抽音         │
│    → 上传临时 OSS → Paraformer │
│    →（可选）译中文 → 删 OSS/本地临时文件 │
│    → 只回 JSON，不存原片        │
└──────────────┬──────────────┘
               │ 公网或同区上传（视轻量机地域）
               ▼
┌──────────────┴──────────────┐
│  北京 OSS（短暂） + 百炼 Paraformer │
│  （同区拉取，避免 OSS 外网流出）   │
└─────────────────────────────┘
```

> 部署约定：新建 **cn-beijing** Bucket 专供临时音频；存储资源包可抵扣容量；Paraformer 拉取走同区。轻量机若不在北京，仍可公网上传该 Bucket。
### 3.1 职责划分

| 组件 | 职责 | 不负责 |
|------|------|--------|
| 前端 | UI、本地播片、跟读录音、字幕持久化、任务进度展示 | 转写算力 |
| Python 服务 | 校验、抽音、调 OSS/Paraformer/翻译、清理、返回结构化字幕 | 当网盘存用户视频 |
| OSS | 给 Paraformer 一个可拉取的短时 URL | 长期媒资库 |
| Paraformer | 日语 ASR + 时间戳 | 中文翻译 |

### 3.2 为什么原片「不存服务器」仍要「上传」

手机无法稳定跑大模型；Paraformer 又需要可访问的音频地址。因此：

1. 用户选本地文件后，**前端仍保留一份用于播放**（不依赖服务器回传视频）。
2. **同一份文件（或仅音频）上传到 Python**，只用于抽音与转写。
3. 服务端处理完删除临时文件与 OSS 对象；响应里**只有字幕 JSON**。
4. 前端把 JSON 写入 IndexedDB，与本地文件指纹（hash / name+size+mtime）绑定。

若上传完整视频过大：优先在服务端 **只保留抽出来的 wav/mp3**，视频字节在入队抽音后尽快丢弃；后续迭代可评估「前端抽音后只传音频」（移动端成本高，MVP 不做）。

## 4. 技术栈

| 层 | 选型 | 说明 |
|----|------|------|
| 前端 | **Svelte 5（或当前稳定 Svelte）+ Vite + TypeScript** | 编译型、运行时轻；`vite build` 出静态资源，Nginx 托管，减轻 2G 机负担 |
| UI / 样式 | **自维护组件 + 自写 CSS**（可用原生 CSS / 少量 CSS 变量） | 临摹 Miraa 交互与版式；**不引入** Element、Ant Design、Vuetify 等重型组件库；不为 PC 后台风 |
| 路由 | `svelte-spa-router` 或官方推荐的轻量 SPA 路由 | Hash/History 皆可；MVP 页面少，保持依赖少 |
| 本地存储 | IndexedDB（`idb` 薄封装即可） | lessons、cues、录音 blob、设置 |
| 播放 | `<video>` / `<audio>` + 自绘字幕轨 | 用 `currentTime` 对齐句子，不用浏览器默认 TTML 当主 UI |
| 录音 | `MediaRecorder` | 跟读对比；权限引导；注意 iOS 手势与格式 |
| 后端 | Python 3.11 + FastAPI | 单进程 + 异步任务或内存队列，**同时只跑 1 个转写任务** |
| 媒体 | ffmpeg / ffprobe | 统一 16 kHz 单声道再送识别（按 Paraformer 要求调整） |
| 对象存储 | 阿里云 OSS **cn-beijing** Bucket | 机器可用公网 endpoint 上传；给百炼签名 URL；生命周期 + 主动删除 |
| ASR | 百炼 `paraformer-v2` | `language_hints: ["ja"]`；用句/词时间戳拼 cue |
| 翻译 | 百炼文本模型或独立翻译 API | 按句或按段翻译成中文；失败时允许「仅日语」降级 |
| 进程管理 | systemd 或 supervisor | FastAPI + Nginx |
| 反向代理 | Nginx | HTTPS、静态资源、`/api` 反代、上传大小限制 |

**不在 MVP 引入**：Redis/Celery（2G 上用进程内队列即可）、Postgres（用户数据在浏览器）、第二台 Whisper 机、React/Vue、UI 组件库、CSS 框架（Tailwind 等非必须；若用也仅作工具类辅助，主视觉仍自维护）。

### 4.1 前端工程约定（已确认）

- **框架**：Svelte + Vite，自己维护页面与组件（课单、播放器、字幕条、跟读控件、进度态等）。
- **样式**：组件内样式 + 全局 design tokens（颜色、字号、安全区 `--sat` / 底栏高度）；优先触控热区 ≥ 44px，竖屏单列。
- **兼容目标**：iOS Safari、Android Chrome 近两个大版本；以真机/devtools 手机尺寸验收，不做 PC 精细布局。
- **产物**：纯静态 `dist/`，无 Node SSR；开发用 Vite dev server，生产只部署构建结果。
- **选型理由**：影子跟读存在高频时间轴状态（当前句、循环、录音态），Svelte 编译后包体小、更新直接，比 React/完整 Vue 更贴合「轻量移动端 Web」。

### 4.2 本地离线缓存与存储设置（已确认）

- 转写成功后：字幕 + 课单元数据写入 IndexedDB；**原片 Blob 默认缓存**。
- 打开课程：先读缓存播放；缓存缺失/损坏 → 引导用户重选本地文件并写回缓存，**不调用转写**。
- 设置页存储区：
  - **只展示已用空间**（`navigator.storage.estimate().usage`），不展示剩余配额。
  - 按播客场景经验阈值着色提示（非硬限制）：

| 已用 | 颜色语气 | 文案方向 |
|------|----------|----------|
| &lt; 1 GB | 正常（绿/主题色） | 空间充足 |
| 1–3 GB | 留意（琥珀） | 缓存渐多，可清理旧课 |
| 3–6 GB | 偏高（橙） | 建议清理不常用缓存 |
| ≥ 6 GB | 告警（红） | 尽快清理，避免占满设备 |

  - 列表支持：**仅清该课原片缓存** / **删除整课（字幕+缓存）**。
- 导出：默认可先做「仅字幕」；后续支持勾选「含原片」大包导出。

## 5. 核心数据流

### 5.1 创建一课（转写）

```
1. 用户选择本地文件 F
2. 前端生成 lessonId，计算指纹，F 进入可播放状态（blob URL）
3. 前端 POST /api/jobs（multipart：文件 + 源语言 ja + 目标翻译 zh）
4. Python：写入 /tmp/{jobId} → ffmpeg 抽音 → 上传 OSS → 提交 Paraformer
5. 轮询/回调拿到 sentences/words（begin_time, end_time, text）
6. 组装 cues[]；调用翻译补 translation 字段
7. 删除 OSS 对象与本地临时文件
8. 返回 { lessonId/jobId, cues, meta }
9. 前端写入 IndexedDB；UI 进入播放/跟读页
```

### 5.2 字幕结构（前后端契约）

```json
{
  "version": 1,
  "sourceLang": "ja",
  "targetLang": "zh-CN",
  "durationMs": 185000,
  "cues": [
    {
      "id": "c001",
      "startMs": 12400,
      "endMs": 15100,
      "text": "今日はいい天気ですね",
      "translation": "今天天气真好啊",
      "words": [
        { "startMs": 12400, "endMs": 12800, "text": "今日" }
      ]
    }
  ]
}
```

- 播放、单句循环、跟读全部只读 `cues`。
- `words` 可选；有则利于逐词高亮与后续点词讲解。

### 5.3 跟读

1. 当前句播放原声（可循环 N 次）。
2. 进入录音态，`MediaRecorder` 写入 blob。
3. 对比态：切换「原声 / 我的录音」或左右/上下双按钮回放（交互对齐 Miraa 的听-说-比）。
4. 录音 blob 存 IndexedDB，键为 `lessonId + cueId`。

## 6. 前端 UI：临摹 Miraa

目标：打开应用后的**主路径、信息层级、跟读节奏**让用过 Miraa 的人感到同构；视觉为自有实现，可调整色板与字体，但**版式与操作顺序对齐**。

实现栈固定为 **Svelte + Vite + 自维护组件/样式**（见 §4.1），用移动端优先的单列布局承载下列界面。

### 6.1 主要界面

| 界面 | 临摹要点 |
|------|----------|
| 首页 / 课单 | 以「我的材料」列表为主；大按钮「导入视频/音频」；少杂讯入口 |
| 导入中 | 明确进度：上传 → 抽音 → 转写 → 翻译；可取消（尽力删除服务端临时对象） |
| 学习主界面 | **上：播放器；中：当前句双语；下：跟读主操作**；不要做成后台仪表盘 |
| 字幕模式 | 原文 / 译文 / 双语切换（对齐 Miraa 字幕显示思路） |
| 跟读态 | 听 → 理解（看译文）→ 跟读 → 回听对比；单句进度清晰 |
| 句列表 | 可点选跳转；当前句高亮；支持单句循环与次数 |
| 设置 | 语速（约 0.5x–1.5x MVP）、默认字幕模式、是否仅 Wi‑Fi 上传（可选） |

### 6.2 交互细则（MVP）

1. **一句一焦点**：主区域始终突出「当前句」，上下句弱化。
2. **变速**：`playbackRate`；MVP 接受变调。
3. **单句循环**：播到 `endMs` 拉回 `startMs`，可设次数或无限。
4. **点句**：点击字幕句 → seek 并设为当前句。
5. **点词（可二期）**：有 `words` 后再做词典/讲解浮层。
6. **安全区**：全面屏底部操作区避开 Home Indicator；顶部避开刘海。
7. **横竖屏**：MVP 只优化竖屏。

### 6.3 视觉原则（在临摹前提下的自有约束）

- 第一屏是**学习构图**，不是功能墙。
- 跟读主按钮视觉权重最高；次要操作用文字按钮。
- 字幕可读性优先：日语主句字号大于译文；对照时译文不压过原文。
- 动效克制：句切换、录音态脉冲等 2～3 处即可。
- 实现前应用真机对照 Miraa 走查一遍「导入 → 出字幕 → 跟读一句」路径，按上述界面清单逐项对齐。

### 6.4 前端路由（建议）

```
/                 课单
/import           导入与任务进度（可用模态代替独立路由）
/lesson/:id       学习主界面（播放 + 字幕 + 跟读）
/lesson/:id/cues  句列表（也可用抽屉）
/settings         设置
```

### 6.5 建议组件拆分（Svelte，自维护）

| 组件 | 职责 |
|------|------|
| `LessonList` | 课单、导入入口 |
| `ImportProgress` | 上传 / 抽音 / 转写 / 翻译进度 |
| `PlayerStage` | video/audio、进度条、播放暂停 |
| `CueFocus` | 当前句日语 + 译文、字幕模式切换 |
| `ShadowControls` | 听 / 跟读 / 回放对比、单句循环、变速 |
| `CueDrawer` | 句列表跳转 |
| `RecordCompare` | MediaRecorder 与原声切换 |

样式与上述组件一并自维护，不依赖第三方 UI 套件。

## 7. 后端 API（草案）

基路径：`/api`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/health` | 健康检查 |
| POST | `/jobs` | 创建转写任务（multipart）；若已有任务在跑返回 409 或排队位次 |
| GET | `/jobs/{id}` | 状态：`queued|running|succeeded|failed` + progress + 结果 cues |
| DELETE | `/jobs/{id}` | 取消并清理临时文件 |

### 7.1 限制（贴合 2G）

- 全局 **concurrency = 1** 转写。
- 上传大小上限（建议视频 ≤ 200MB，可配置）；超时与最大时长（建议 ≤ 30 分钟素材，更长拒绝或提示切片）。
- 临时目录磁盘水位监控；超过则拒绝新任务。
- 所有成功/失败路径都走 `finally` 删除本地临时文件与 OSS 对象。

### 7.2 OSS 与费用注意

- Bucket 与百炼同地域；ECS 用**内网 endpoint** 上传。
- 对象 ACL/签名 URL 仅满足 Paraformer 拉取；尽量短 TTL。
- 公网 URL 会产生 OSS 流出；同区内网拉取可避免大部分外网流量（以阿里云当前计费规则为准）。
- Paraformer 本身按语音时长计费（约 0.288 元/小时量级，以控制台为准）；**不含翻译费**。

## 8. 安全与隐私

- HTTPS 全站。
- 上传接口可加简单共享密钥 / 邀请码（MVP 防扫）；正式账号体系二期。
- 日志禁止打印用户音频路径外的文件内容；不落用户原片到非临时目录。
- OSS 前缀隔离 `tmp/{jobId}/`；生命周期规则：1 天强制过期作兜底。
- 前端说明：转写需将音频发送至云端识别，原片不在服务器长期保存。

## 9. 部署（单机 2 核 2G）

```
/var/www/snsn/          前端 dist
/opt/snsn-api/          FastAPI 应用
/tmp/snsn-jobs/         临时媒资（定期清理）
Nginx :443 → / 静态, /api → 127.0.0.1:8000
```

- 系统保留内存；ffmpeg + FastAPI 峰值需防 OOM（单任务）。
- 不在此机跑 Whisper 权重。
- 前端纯静态，避免 Node SSR 常驻。

## 11. 风险与对策

| 风险 | 对策 |
|------|------|
| 2G 内存在 ffmpeg 高峰 OOM | 限制并发与分辨率；先转码再识别；监控 |
| 大视频上传慢/失败 | 压缩提示、断点（二期）、超时重试、只鼓励短素材 |
| Paraformer 日语专有名词错误 | 允许用户改 cue 文本（二期）；热词若有再接 |
| 浏览器杀后台导致 blob 释放 | 原片进 IndexedDB 缓存；失败时重选本地文件，不重转写 |
| 本地缓存占空间 | 设置页展示已用并按阈值着色；支持按课清缓存/删课 |
| iOS Safari 录音/自动播放限制 | 跟读须用户手势触发；备选格式 |
| UI「临摹」边界 | 对齐交互，不复制商标与官方切图 |
